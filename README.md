# Operation GO 🚀

A modern, high-impact non-profit organization web platform empowering youth and communities through leadership, education, and technology.

---

## 🌟 Key Features

- **Multi-page Experience**:
  - `index.html` - Homepage with Hero, stats, mission, and program highlights
  - `about.html` - Mission, values, leadership team, and organizational story
  - `programs.html` - Educational and community empowerment initiatives
  - `careers.html` - Open positions and culture
  - `get-involved.html` - Volunteer and partnership opportunities
  - `impact.html` - Measurable community impact, statistics, and testimonials
  - `support-us.html` - Contribution channels and donation tiers
  - `contact.html` - Inquiry forms and direct contact points
- **Advanced GSAP Motion System**:
  - Ambient scroll-following reactive glow spotlight
  - Smooth page reveals and stagger micro-animations
  - Fully responsive mobile drawer navigation
  - Accessible and reduced-motion compliant
- **Lovable.dev Ready**:
  - Pre-configured with modern `package.json` and `vite.config.js` for instant dev preview and multi-page routing.

---

## 🛠️ Quick Start

### Option 1: Using Vite (Lovable / Standard Dev Server)
```bash
npm install
npm run dev
```

### Option 2: Using Node.js Built-in Server
```bash
node server.js
```
The server will start at `http://localhost:3000`.
